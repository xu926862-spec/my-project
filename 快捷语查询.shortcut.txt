📱 快捷指令使用说明
==================

【方法1】导入 JSON 文件（推荐）
1. 在文件应用中找到 shortcuts_list.json
2. 用快捷指令打开它
3. 在快捷指令中使用以下操作：

快捷指令代码流程：
1. [获取文件] → shortcuts_list.json
2. [从文本获取] → 获取文件内容
3. [用"从JSON获取值"]
4. [选择菜单] → 显示所有快捷语
5. [复制到剪贴板] → 复制选中的快捷语

【方法2】创建"快捷语查询"快捷指令
1. 打开"快捷指令"应用
2. 创建新快捷指令
3. 添加操作：
   - 要求提供: 文本/菜单选项
   - 搜索功能
   - 复制到剪贴板

【方法3】自动化 - Siri 语音触发
1. 在快捷指令中创建"询问"功能
2. 说出快捷语前几个字
3. 自动显示相关快捷语
4. 一键复制

📁 文件说明：
- shortcuts_config.plist  : 原始 plist 格式
- shortcuts_list.json     : JSON 格式（推荐导入）
- shortcuts_list.txt      : 文本格式（可选）
